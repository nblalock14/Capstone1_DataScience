**Author: Nick Blalock**

## Project Overview

This project explores the Federal Housing Finance Agency (FHFA) House Price Index dataset to better understand housing-market trends across the United States. The analysis examines the structure of the dataset, summarizes its major variables, identifies missing values, and compares changes in house prices across time and geographic markets.

## Data Source

The primary dataset used in this project is the FHFA House Price Index Master Dataset.

Source: https://www.fhfa.gov/data/house-price-index

The dataset was accessed on September 11, 2026.

## Analysis

The project includes:

- An overview of the FHFA House Price Index dataset and its attributes
- Summary statistics for the major numerical variables
- Analysis of missing values
- U.S. House Price Index trends over time
- Five-year HPI growth comparisons across states
- Comparison of one-year and five-year state-level HPI growth

## Key Findings

The analysis shows that U.S. residential property values have generally increased over time, although the rate of appreciation has varied across different periods.

State-level analysis also shows significant geographic differences in house-price growth. In addition, states with strong longer-term appreciation do not always experience the strongest recent growth, showing the importance of considering both short-term and long-term trends when analyzing housing markets.

## Additional Real Estate Data

The Zillow Observed Rent Index (ZORI) was identified as an additional dataset that could complement the FHFA data. While the FHFA House Price Index measures changes in property values, rental data can provide information about potential rental income and changes in rental-market conditions.

Zillow Data: https://www.zillow.com/research/data/
